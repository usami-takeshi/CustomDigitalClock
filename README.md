# CustomDigitalClock - モーフィングデジタルクロック

アニメーションの課題制作やクリエイティブな表現のための、カスタマイズ可能なデジタル時計Webアプリケーションです。  
ユーザが作成した数字のモーフィングアニメーション素材（1秒間/30fps/500x500px）を読み込み、Webブラウザ上でリアルタイムに時計として動作確認・鑑賞・共有できます。

🌐 **オンライン公開URL**: [https://usami-takeshi.github.io/CustomDigitalClock/](https://usami-takeshi.github.io/CustomDigitalClock/)  
（※ GitHub Pages 有効化後に世界中からアクセス可能になります）

---

## 🌟 主な機能と特徴

### 1. 2つの素材形式に対応 & アコーディオンUI
- **透過動画 (WebM/MP4)**: After Effects等からの書き出し向け
- **連番画像 (PNG)**: Procreateやペイントツールからの書き出し向け
- 各種設定項目（アセット、表示、背景、音、共有）はアコーディオンバーで自由に折りたたんで格納できます。

### 2. ドラッグ＆ドロップで誰でもカスタマイズ
- ブラウザ画面に自分の **素材フォルダ（`assets` フォルダや `0_to_1` フォルダ、または動画ファイル）をドラッグ＆ドロップ** するだけで、サーバー通信不要で即座に読み込まれて再生されます。
- 右上の設定パネルから **「📥 フォルダ選択読込」** ボタンでも読み込み可能です。

### 3. 文字間隔・コロン間隔の個別調整
- **数字前後の間隔（文字間）**: 各数字同士の間隔をピクセル単位で微調整可能。
- **コロン前後の間隔**: コロン（:）と数字の間の左右余白を個別に調整可能。
- 時計全体の拡大率（スケール）調整にも対応。

### 4. 背景映像・画像の追加
- 好きな動画（.mp4, .webm）や画像（.jpg, .png）を画面全体の背景として追加可能。
- **背景の暗さ（文字強調）** スライダー（文字を見やすくするオーバーレイ調整）。
- **背景のぼかし (Blur)** スライダー（動画や画像を柔らかくぼかすエフェクト）。

### 5. サウンド機能
- **素材動画の音を鳴らす**: WebM/MP4に含まれる音声トラックの再生ON/OFF。
- **毎秒のカウント音 (SE)**: 時計音（チクタク）、電子音（ピッ）、ソフトポップ、または**カスタム音声ファイル**（.mp3, .wav）の読み込みに対応。
- 全体音量スライダー搭載。

### 6. 設定の保存・読込・URL共有
- **自動保存**: 調整したレイアウトや配色、音量はブラウザに自動保存されます。
- **共有リンクのコピー**: 現在の設定を含んだ専用URLをワンクリックでコピー。相手にURLを送るだけで、同じレイアウト・配色設定で開くことができます。
- **設定ファイル (JSON)**: プリセットをJSONファイルとして保存・読み込み可能。

## 🚀 使い方・起動方法

### A. Webブラウザで使う場合（推奨）
1. [公開URL](https://usami-takeshi.github.io/CustomDigitalClock/)（またはローカルで `index.html`）をブラウザで開きます。
2. 画面上に自分の素材フォルダをドラッグ＆ドロップするだけで、すぐに時計として動きます！

### B. ローカルでデスクトップアプリとして使う場合
- **Mac**: フォルダ内の `DigiClock.app`（または `Start_Mac.command`）をダブルクリック。
- **Windows**: フォルダ内の `Start_Windows.bat` をダブルクリック。
- **PWA**: ブラウザのアドレスバー右側から「アプリをインストール」をクリック。

## 📁 フォルダ構成
```text
CustomDigitalClock/
├── index.html        # アプリ本体（HTML5 / ドラッグ＆ドロップ対応）
├── style.css         # スタイル（CSS変数・折りたたみバー・背景レイヤー）
├── script.js         # 時計ロジック・音源エンジン・プリローダー・共有機能
├── manifest.json     # PWA（デスクトップアプリ化）定義
├── server.py         # Finder連携対応ローカルWebサーバー
├── DigiClock.app     # Mac用ワンクリック起動アプリ
├── Start_Mac.command # Mac用起動スクリプト
├── Start_Windows.bat # Windows用起動バッチ
├── README.md         # 本説明書
└── assets/
    ├── webm/         # 透過動画配置フォルダ (0_to_1.webm サンプル同封)
    └── png/          # 連番画像配置フォルダ (0_to_1/frame_00.png〜 サンプル同封)
```

## 🎨 素材の作成仕様（規格）
- **デュレーション**: 1.0秒間（ちょうど30フレーム）
- **フレームレート**: 30 fps
- **解像度**: 500 × 500 px（正方形）
- **背景**: 透過（アルファチャンネル付き）

---

## 🛠 素材の配置ルール
- **透過動画**: `assets/webm/{from}_to_{to}.webm`（例: `0_to_1.webm`, `9_to_0.webm`）
- **連番画像**: `assets/png/{from}_to_{to}/frame_00.png` 〜 `frame_29.png`
